## Mikä tämä on?

**MATLAB + Claude for Engineers** on aloittelijaystävällinen paketti tekniikan opiskelijoille. Sen avulla Claude Code (tekoälyavustaja, joka toimii terminaalissa) laskee insinöörilaskut oikeasti koodilla eikä arvaa lukuja päässään. ## Testiajo

Esimerkissä `examples/plasticity/von_mises_yield_check.py` jännitykset ovat σx = 180, σy = 60 ja τxy = 40 MPa, ja myötöraja σy = 250 MPa:

- Pääjännitykset: σ₁ = 192.11 MPa, σ₂ = 47.89 MPa, σ₃ = 0
- von Mises: σ_vm = **173.21 MPa**, josta varmuuskerroin n = 250 / 173.21 = **1.443**
- Tresca: σ_T = 192.11 MPa, josta n = **1.301**
- **Johtopäätös:** kappale ei myödä, vaan pysyy kimmoisena (n > 1).

Tresca antaa aina pienemmän varmuuskertoimen, eli se on varovaisempi kriteeri. Siksi CLAUDE.md käskee näyttää molemmat.
