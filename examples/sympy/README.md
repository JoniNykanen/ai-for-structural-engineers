# SymPy (symbolic) examples

Exact, symbolic derivations — the algebra a textbook shows, done by the computer
with no rounding. **No MATLAB license needed.**

| File | What it does |
|---|---|
| `symbolic_yield_derivation.py` | Derives the von Mises equivalent stress from the deviatoric stress tensor, then differentiates the yield function to get the associated-flow plastic-strain directions |

## Run it

```bash
python symbolic_yield_derivation.py
```
