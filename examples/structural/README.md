# Structural examples

Real engineering coursework solved in MATLAB — beyond plasticity — to show the
kit works across mechanics/structures topics.

| File | What it does | Needs MATLAB? |
|---|---|---|
| `mahapalkki_GL30c_mitoitus.m` | Curved glulam beam (GL30c, 21 m span) design to **Eurocode 5** (EN 1995-1-1) + Finnish National Annex: load combinations, bending, shear, deflection, and the radial tension check specific to curved beams. Written in MATLAB **plain-text Live Script** format. *In Finnish.* | ✅ |

## Run it

In MATLAB, open the `.m` file and Run — or ask Claude to run it via the MATLAB
Engine API / MCP server (see `docs/03`, `docs/04`).

> This is a worked, real example of "engineering calculation, done with MATLAB +
> Claude." Adapt the inputs at the top of the file to your own beam.
